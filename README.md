# Library Management System

A console-based Library Management System developed using Core Java as part of my Java Development Internship.

## Features

- Add new books with unique IDs
- Remove books from the library
- Display all available books
- Search books by ID or title
- Issue books
- Return issued books
- Track book availability status

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner Class
- Loops and Conditional Statements

## Project Structure

```text
Library-Management-System/
│
├── Main.java
├── Book.java
└── README.md
```

## How to Run

Compile:

```bash
javac Book.java Main.java
```

Run:

```bash
java -cp . Main
```
